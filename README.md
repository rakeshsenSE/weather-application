# 🌦️ LangChain Weather App

A modern Desktop Weather Application built using Python's **Tkinter** for the graphical interface and **LangChain Community Utilities** for robust API data fetching. It securely connects to the **OpenWeatherMap API** to fetch and display real-time, live weather analytics within a clean and dynamic user interface.

---

## ✨ Features

* **AI-Ready Integration:** Leverages LangChain's production-grade `OpenWeatherMapAPIWrapper` instead of standard raw HTTP requests.
* **Secure API Handling:** Integrates `python-dotenv` to safeguard sensitive API credentials inside a local `.env` file, preventing accidental exposure on GitHub.
* **Interactive GUI:** Features a clean layout, customized text-wrapping for detailed summaries, structured paddings, and precise pop-up error handling via Tkinter's `messagebox`.
* **Comprehensive Live Data:** Displays real-time temperatures, wind velocities, humidity percentages, and cloud conditions instantaneously.

---

## 🛠️ Technology Stack

* **Language:** Python 3.x
* **GUI Framework:** Tkinter
* **AI/LLM Ecosystem Framework:** LangChain (Community Utilities)
* **API Engine Dependency:** PyOWM (Python OpenWeatherMap)
* **Environment Management:** Python-DotEnv
